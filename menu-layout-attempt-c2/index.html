        Prototype — header centré sur le logo

        Le logo reste un ancrage fixe au centre du viewport. La navigation est un seul menu à plat (le logo y occupe conceptuellement une position, comme un item parmi les autres pour la personne qui édite le menu) ; ici le script le simule en répartissant un tableau de liens en deux groupes avant/après le logo. Le repli en hamburger est déclenché par un vrai constat de dépassement (largeur réelle nécessaire > largeur disponible), pas par un point de rupture fixe — donc il se déclenche aussi bien sur mobile que sur un grand écran si la liste de liens est longue.
